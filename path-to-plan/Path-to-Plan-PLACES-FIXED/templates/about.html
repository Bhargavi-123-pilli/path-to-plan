ABOUT THE PROJECT

Path to Plan

A full-stack travel planning assistant built with Flask, SQLite and open mapping services.

How it works

  1. Search a starting location.
  2. Search and select a destination.
  3. Calculate a route with OSRM.
  4. Explore nearby places with OpenStreetMap/Overpass.
  5. Save the journey in SQLite.

Data accuracy

Path to Plan does not invent names, ratings, prices, phone numbers or schedules. If mapped information is unavailable, the interface says so.

Nearby place information is provided for reference. Please verify availability and contact details before relying on it.
